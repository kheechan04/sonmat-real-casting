## 전작 녹화로 미리 본 것 (참고용, 판정 근거로 쓰지 않음)

Shadow Mitts 녹화(사용자 본인, 사우스포 복싱)를 `npm run analyze -- --rod=left`로 돌려 본 결과:

- **카메라 쪽으로 뻗는 동작에서 월드 z가 "증가"했다.** 리어 크로스 4/4회, 높은 크로스 4/5회에서 손목 z가 +0.07\~+0.26m.
  문서상 관례(−z = 카메라 쪽)와 반대지만 **방향은 일관적**이다. 캐스팅 판정에 z를 "부호만" 쓸 수 있는지 A3·B1에서 본다.
- **카메라 쪽으로 팔을 쭉 뻗어도 3D 팔꿈치 각도가 거의 안 펴졌다**(76°→70° 등). 깊이 방향 움직임이 월드 좌표에서 눌려 보인다는 뜻 →
  정면 캐스팅은 화면상 **위→아래 궤적과 속도(2D)** 가 주 신호가 될 가능성이 높다. 비교용으로 옆으로 서서 하는 B2를 넣었다.
- 이미지 좌표는 **어깨너비가 아니라 몸통 길이(어깨 중심→골반 중심)로 나눠야** 한다. 옆으로 선 자세에서 어깨너비가 0에 가까워져,
  가만히 있는데 속도가 275/s로 나왔다. `src/core/analysis.ts`의 `torsoImg`.
- 프레임 사이 흔들림: 50fps에서 인접 프레임 속도만 보면 가만히 있어도 7\~9 몸통길이/s가 나온다. ±50ms 구간 속도로 바꾸니 2.3\~3.6,
  실제 팔 동작은 6.7\~9.5 → 빠른 동작 기준 4(임시값). 녹화 E1(가만히)로 다시 정한다.
