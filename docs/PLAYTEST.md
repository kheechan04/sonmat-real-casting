# 플레이테스트 안내 (M2)

## 실행

```
cd C:\Users\user\Desktop\sonmat-real-casting
npm run dev
```

브라우저에서 http://localhost:5173 → 대 드는 손 고르기 → **카메라 켜고 시작** (호수를 불러오는 몇 초 동안은 버튼이 잠겨 있어요).
**배꼽 위 상반신**만 화면에 들어오면 돼요 (허리까지 안 보여도 돼요).
관절 좌표 관찰 도구(M0)는 http://localhost:5173/observe.html

## M2에서 바뀐 것

- 시작하면 **장소**를 골라요: 저수지 / 바다(갯바위) / 심해(노을 선상, 찌 없이 대 끝으로 입질) / 아프리카 강
- 장소마다 미끼와 물고기가 달라요. 46종 — 흔함·보통·희귀·전설. 오른쪽 위 📖 **도감**에서 모은 걸 볼 수 있어요
- **아주 가끔** 수달·범고래·나일악어가 걸린 물고기를 노리고 다가와요 → 제한 시간 안에 **빨리 감으면 따돌려요**.
  아프리카 강에선 하마가 떠오르기도 해요 (물고기가 흩어져서 다시 기다려요)
- 물고기 모양은 코드로 만든 3D예요. 전체 모습은 http://localhost:5173/models.html 에서 한눈에 볼 수 있어요

## 한 판의 흐름

1. **미끼 고르기** — 지렁이(입질 빠름, 붕어·작은 편) / 떡밥(보통, 고루) / 옥수수(느림, 큰 잉어)
2. **던지기** — 대 든 손을 머리 뒤로 젖혔다가 앞으로 휘두르기. 세게 휘두를수록 멀리 날아가요
3. **찌 보기** — "톡톡" 살짝 흔들리는 건 간만 보는 거예요. 이때 채면 놓쳐요
4. **챔질** — 붕어는 찌가 **스르륵 올라오고**, 잉어는 **쭉 빨려 들어가요**. 그때 손을 빠르게 위로 "툭"
5. **감기** — 릴 손으로 작은 원을 계속. 빠르게 돌릴수록 빨리 감겨요 (어느 속도 이상은 같아요)
6. **차고 나갈 때** — "첨벙!" 예고 → 대가 크게 휘고 "지이익" 소리, 화면 테두리가 붉어지고 남은 줄이 늘어나요.
   이때 감으면 **줄 긴장** 게이지가 차올라요. 끝까지 차면 끊어져요. **손을 멈췄다가** 잠잠해지면 다시 감아요
7. **결과** — 붕어 30.3cm 이상이면 "월척!", 개인 기록도 기억해요

오른쪽 위 **?** 에 같은 설명이 있어요. 웹캠 화면은 S/M/L로 크기를 바꿀 수 있어요.

## 봐 주셨으면 하는 것

- 빠르게 감아도 잘 감기는지 (이번에 방식을 바꿨어요)
- 차고 나가는 순간을 보고/듣고 바로 알 수 있는지, 멈추기가 자연스러운지
- 새 미끼 3종이 고르는 재미가 있는지
- 배경·UI가 괜찮은지, 더 바꾸고 싶은 곳

## 가까이 서서 녹화 부탁 (F1\~F4)

허리가 안 보이게 가까이 서도 인식이 되는지 확인하려고 해요. 관찰 도구(observe.html)의 체크리스트에서 **F1\~F4**를 녹화해 주세요.
캐스팅 10회 / 짧은 챔질 10회 / 릴링(앞 10초 보통, 뒤 10초 빠르게) / 대기 중 움직임 — 각각 20\~30초예요.

## 숫자 조정 (⚙ 버튼)

**모든 임시값을 슬라이더로** 바꿀 수 있어요. **바뀐 값 복사** → 대화에 붙여 주면 기본값으로 옮길게요.
인식이 이상했던 판은 ⚙ → **마지막 판 녹화 저장**으로 파일을 받아 `recordings/`에 넣어 주세요 (좌표만 들어 있어요).

- 어종은 붕어·잉어 2종만 (M2에서 늘려요)
