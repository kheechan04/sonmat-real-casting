# M1 플레이테스트 안내

## 실행

```
cd C:\Users\user\Desktop\sonmat-real-casting
npm run dev
```

브라우저에서 http://localhost:5173 → 대 드는 손 고르기 → **카메라 켜고 시작**.
관절 좌표 관찰 도구(M0)는 http://localhost:5173/observe.html 로 옮겼어요.

## 한 판의 흐름

1. **미끼 고르기** — 화면의 카드 클릭 (고무 / 일반 / 갯지렁이, 입질 빈도만 달라요)
2. **던지기** — 대 든 손을 머리 뒤로 젖혔다가 앞으로 휘두르기. 세게 휘두를수록 멀리 날아가요
3. **기다리기** — 찌가 "톡톡" 흔들리는 건 가짜 입질이에요. 이때 채면 놓쳐요
4. **챔질** — 찌가 쑥 들어가고 "지금! 채요!"가 뜨면 손을 빠르게 위로 "툭". 노란 막대가 줄어들기 전에
5. **감기** — 릴 손으로 작은 원을 계속. "물고기가 당겨요!"가 뜨면 잠깐 멈춰요 (계속 감으면 긴장도가 차서 줄이 끊어져요)
6. **결과** — 어종·길이·무게. 크거나 희귀한 물고기(잉어)일수록 감아야 하는 횟수가 많아요

## 봐 주셨으면 하는 것

- 던지기·챔질이 **내가 한 만큼 잡히는지**, 안 했는데 잡히는 건 없는지 (카메라 화면 아래에 인식된 동작이 잠깐 표시돼요)
- 가짜 입질과 진짜 입질이 **찌만 보고 구분되는지**
- 챔질 제한 시간(붕어 1.2초, 잉어 2초)이 너무 빡빡하거나 널널하지 않은지
- 미끼별 대기 시간이 지루하지 않은지 (고무 미끼 25\~40초)
- 릴링 길이(붕어 약 14\~26회, 잉어 약 32\~59회)와 당김 빈도가 적당한지

## 숫자 조정 (⚙ 버튼)

오른쪽 위 ⚙에서 **모든 임시값을 슬라이더로** 바꿀 수 있어요. 바꾼 값은 이 브라우저에 기억되고, 노란 글씨로 표시돼요.
마음에 드는 값이 되면 **바뀐 값 복사** → 대화에 붙여 주세요. 코드의 기본값으로 옮겨 둘게요.

인식이 이상했던 판은 ⚙ → **마지막 판 녹화 저장**으로 파일을 받아 `recordings/`에 넣어 주세요 (좌표만 들어 있어요).
그 판의 관절 좌표와 게임 기록을 보고 원인을 찾을 수 있어요.
