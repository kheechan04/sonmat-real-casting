# 개인정보 — 카메라와 "내 얼굴 인면어"

손맛: 리얼 캐스팅은 웹캠으로 몸 동작을 읽는 게임이에요. 영상과 얼굴이 어떻게 다뤄지는지 정리한 문서예요.
(M4 시작 전 DESIGN.md §6 체크리스트를 사용자와 함께 확인함, 2026-09-26)

## 약속

| # | 약속 | 어떻게 지키나 |
|---|---|---|
| 1 | 카메라 영상은 **브라우저 밖으로 나가지 않아요** | 포즈 인식(MediaPipe)은 브라우저 안에서 돌아요. 소스 어디에도 데이터를 보내는 코드(fetch·XHR·beacon·WebSocket 등)가 없어요 — `tests/privacy.test.ts`가 매번 검사해요. |
| 2 | 게임 페이지는 **정해진 곳에만 연결**할 수 있어요 | `index.html`의 CSP: 연결은 이 사이트, 포즈 모델을 받는 두 곳(cdn.jsdelivr.net, storage.googleapis.com), 페이지 안 메모리(blob:/data:)만. 코드에 실수가 있어도 다른 곳으로는 브라우저가 막아요. |
| 3 | 얼굴 사진은 **이 기기(브라우저)에만** | "내 얼굴 인면어"를 만들 때만 찍어요. 256×256 한 장을 이 사이트의 IndexedDB에만 저장해요 — localStorage·URL·서버에는 없어요 (`src/app/face.ts`). |
| 4 | **먼저 동의** | 얼굴이 없으면 시작할 때마다 촬영 창이 뜨지만("나중에"로 닫기), 촬영 창에서 "위 내용을 확인했어요"에 체크해야 미리보기와 촬영이 켜져요. 찍은 뒤 미리 보고 다시 찍을 수 있어요. |
| 5 | **나만** 찍히게 | 촬영 창 안내 + 포즈 인식은 한 사람만 추적해요(그 사람의 코·눈·귀 둘레만 잘라요). |
| 6 | 언제든 **삭제** | 도감 → 이벤트 → "내 얼굴 삭제". 저장소(데이터베이스)째 지워져서 남는 게 없고, 인면어도 바로 안 나와요. |
| 7 | 기본은 **꺼짐** | 얼굴을 등록하지 않으면 인면어는 안 나오고 얼굴을 따로 찍지도 않아요. |
| 8 | 화면 공유 주의 | 인면어를 낚으면 내 얼굴이 화면에 크게 나와요 — 촬영 창에 안내해요. |

## 저장되는 것 전부

| 무엇 | 어디 | 지우는 법 |
|---|---|---|
| 얼굴 사진 1장 (인면어를 만들었을 때만) | IndexedDB `sonmat-face` | 도감 → 이벤트 → 내 얼굴 삭제 |
| 설정·기록 (대 드는 손, 카메라 선택, 창 크기, 소리, 잡은 기록) | localStorage `sonmat.*` | 브라우저의 사이트 데이터 삭제 |

녹화 도구(`/observe.html`)의 녹화 파일에는 관절 좌표만 있고 영상은 없어요. 분석 도구(Analytics 등)는 붙이지 않아요.
