# 손맛: 리얼 캐스팅

웹캠 앞에서 **몸으로 던지고, 채고, 감는** 낚시 게임이에요. 설치 없이 브라우저에서 바로 할 수 있어요.

**플레이: https://sonmat-real-casting.vercel.app**

- **던지기** — 대 든 손을 머리 뒤로 젖혔다가 앞으로 휙
- **챔질** — 찌가 움직이면 손을 빠르게 위로 "툭"
- **감기** — 반대 손으로 릴을 돌리듯 작은 원을 계속. 물고기가 차고 나가면 잠깐 멈춰요

새 떼·물 끓음 쪽으로 겨냥해 던지면 큰 물고기가 잘 물고, 옆으로 차고 나가면 대 든 팔을 반대로 옮겨 버텨요.
저수지·바다·심해·아프리카 강에서 46종을 낚아 도감을 채워요. 문어, 대왕오징어, 실러캔스, 덤보문어, 가시복, 백상아리, 귀상어, 청새치, 심해아귀, 귀신고기, 산갈치,
골리앗 타이거피시, 나일퍼치, 황쏘가리… 그리고 아주 가끔 수달·범고래·악어·하마가 끼어들어요.

시간은 내 컴퓨터 시계를 따라 **낮·노을·밤**으로 바뀌어요(장소 고르는 창에서 직접 고를 수도 있어요). 밤엔 달빛과 전자찌.
얼굴을 등록하면 가끔 **내 얼굴을 한 인면어**가 낚여요. 잡은 물고기는 📸 기념사진으로 저장할 수 있어요.

## 앱으로 설치 (PWA)

크롬·엣지 주소창 오른쪽의 설치 아이콘(또는 메뉴 → "앱 설치")을 누르면 바탕화면·시작 메뉴에서 창 하나로 열려요.
한 번 온라인에서 플레이하고 나면 **인터넷 없이도** 돼요(게임 파일과 포즈 인식 모델을 이 기기에 보관해요).

## 준비물

- 웹캠이 달린 PC, 크롬 또는 엣지
- **배꼽 위 상반신**이 화면에 들어오게 서기 (1.5m쯤). 빈손으로 해요
- 밝은 방이 좋아요 (어두우면 웹캠이 느려져요)

## 개인정보

카메라 영상은 **이 브라우저 안에서만** 처리되고 어디에도 전송되지 않아요. 포즈 인식(MediaPipe)도 브라우저 안에서 돌아요.
기록(도감·최고 기록)과 인면어 얼굴 사진은 이 브라우저에만 저장돼요. 자세한 약속은 [docs/PRIVACY.md](docs/PRIVACY.md).

## 직접 실행하기

```
npm install
npm run dev        # http://localhost:5173
npm test           # 인식·게임 규칙 테스트 (카메라 불필요)
npm run build      # dist/ 에 배포용 파일
```

`/observe.html` 관절 좌표 관찰 도구, `/models.html` 어종 모델 갤러리, 주소 뒤 `?dev` 설정값 패널(⚙).
