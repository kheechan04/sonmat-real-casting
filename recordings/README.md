# recordings/

M0 관찰 도구로 저장한 관절 좌표 JSON을 두는 곳이다.
개인 동작 데이터라 **저장소에는 포함하지 않는다** (`.gitignore`로 제외). 영상은 들어 있지 않고 좌표만 있다.

## 녹화하는 법

1. `npm run dev` → 브라우저에서 http://localhost:5173
2. "낚싯대 드는 손"을 고르고 **카메라 시작**. 상반신과 머리 위로 뻗은 손까지 화면에 다 들어오게 선다(2\~3m).
3. 오른쪽 "녹화 (체크리스트)"에서 항목을 고르면 메모·자동 정지 시간이 채워진다. **녹화 시작** → 3초 카운트다운 → 동작.
4. 멈추면 `rec-날짜-시간.json`이 내려받아진다. 이 폴더로 옮긴다. 다음 항목이 자동으로 선택된다.
5. `npm run analyze` 로 전부 분석 (특정 파일만: `npm run analyze -- recordings/rec-….json`).

메모는 분석 스크립트가 읽어서 "무엇을 한 녹화인지" 안다. 체크리스트 항목의 메모는 가급적 고치지 않는다
(자유 녹화는 "(직접 입력)"으로 아무 메모나).

## 체크리스트 (M0)

| 번호 | 동작 | 길이 | 보는 것 |
|---|---|---|---|
| A1 | 대 손을 몸 바깥 옆으로 뻗기 3회 | 12초 | x축 방향 |
| A2 | 대 손을 머리 위로 뻗기 3회 | 12초 | y축 방향 |
| A3 | 대 손을 카메라 쪽으로 천천히 뻗기 3회 | 12초 | **z축 방향·깊이 신뢰도** |
| A4 | 릴 손만 위로 3회 | 10초 | 좌/우 라벨 |
| B1 | 오버헤드 캐스팅 10회 (정면) | 30초 | 캐스팅 궤적·속도 |
| B2 | 오버헤드 캐스팅 5회 (옆으로 서서) | 20초 | 정면 vs 옆 비교 |
| B3 | 사이드 캐스팅 10회 (정면) | 30초 | 대안 동작 |
| C1 | 큰 챔질(머리 위까지) 10회 | 30초 | 캐스팅과 구분되는지 |
| C2 | 짧은 챔질(가슴 높이까지 "툭") 10회 | 30초 | 작은 챔질의 속도·크기 → 판정 기준 |
| C3 | 챔질 크기 섞어서 10회 | 40초 | 작은 것도 빠짐없이 잡히는지 |
| D1 | 릴링 20초 — 실제 릴처럼 앞뒤로 도는 원 | 20초 | 원이 어느 면에 보이는지 |
| D2 | 릴링 20초 — 화면에 원 그리기 | 20초 | D1과 비교 |
| D3 | 빠른 릴링 20초 (실제 방향) | 20초 | 빠를 때 인식 |
| E1 | 대기 자세로 가만히 20초 | 20초 | 잡음 기준 |
| E2 | 한 사이클 3회 (캐스팅→대기→챔질→릴링) | 60초 | 실제 흐름 |
| E3 | 입질 대기 중 자연스럽게 움직이기 (챔질 안 함) | 30초 | 챔질로 잘못 잡히는 움직임 |
| F1~F4 | **가까이 서서(배꼽 위까지만 보이게)** 캐스팅 10회 / 짧은 챔질 10회 / 릴링(보통→빠르게) / 대기 중 움직임 | 20~30초 | 골반이 화면 밖이어도 인식이 되는지 (B1·C2·D1·E3와 비교) |
| G1~G3 | 가까이: **왼쪽 겨냥** 캐스팅 5회 / **오른쪽 겨냥** 5회 / 왼쪽→가운데→오른쪽 2바퀴 | 20~40초 | M3 포인트 공략: 던지는 방향을 손 궤적으로 구분할 수 있는지 |
| G4 | 가까이: **펌핑** — 대 손을 천천히 들어 올렸다가 빠르게 내리면서 반대 손으로 감기, 반복 | 30초 | M3 펌핑: 대 드는 동작이 감기·챔질과 구분되는지 (챔질로 잘못 잡히면 안 됨) |
| G5 | 가까이: 감으면서 **대를 좌우로 눕히기** (왼쪽 3초 → 가운데 → 오른쪽 3초 → 가운데) | 30초 | M3 로드워크: 대 기울기(손의 좌우 위치)가 안정적으로 읽히는지 |

빈손으로 한다. 반대 손 설정은 `npm run analyze -- --mirror`(좌우 반전)로 검사하므로 한 손 설정만 녹화하면 된다.
시간이 되면 CPU로 한 번, "GPU로 인식"을 켜고 한 번 녹화해 두면 fps 비교가 된다.

## 형식 (v1, Shadow Mitts와 호환)

```jsonc
{
  "meta": { "version": 1, "createdAt": "...", "note": "오른손 대, 오버헤드 캐스팅 10회 (정면)",
            "aspect": 1.333, "videoWidth": 640, "videoHeight": 480, "model": "lite", "delegate": "CPU",
            "rodHand": "right", "mirrorView": true, "cameraFps": 30 },   // 마지막 3개는 이 프로젝트에서 추가(선택)
  "frames": [
    { "t": 0,      // ms, 첫 프레임 = 0
      "lm": [[x, y, z, visibility], ...33],   // 정규화 이미지 좌표 (거울 반전 전), 사람이 없으면 null
      "wl": [[x, y, z, visibility], ...33],   // 월드 좌표(m)
      "ms": 21.3 } // 이 프레임의 추론 시간(선택)
  ]
}
```
